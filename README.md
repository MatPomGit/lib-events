# Event Validation and Delivery

Experimental Python library for schema subset validation, delivery state checks and stable event identity. No network transport or participant upload. Author: Mateusz Pomianek.

## Local development

Python 3.11 or newer. Install locally with `python -m pip install .`; run `python -m unittest discover -s tests -v`. See [API contract](contracts/api.json), [documentation](docs/contracts.md) and [limitations](docs/compatibility.md). No published package.

The original migration snapshot is reference material, not part of the installed API. License review for the complete repository remains open.
